Pilot profile

Precision in the air. Clarity on the ground.

I’m a UAV pilot and LiDAR operator who has run the Metron X 3D LiDAR system on mining and geospatial projects for some of India’s biggest industrial sites. I plan the mission, fly it safely with strict pre- and post-flight checks, and process the data myself in CloudCompare, DJI Terra, Metashape and Global Mapper.

I also build my own tools — custom LiDAR rigs, SLAM pipelines and web dashboards — so when a project needs something off the shelf can’t do, I can make it. My goal: push UAV technology further into innovative geospatial solutions.
